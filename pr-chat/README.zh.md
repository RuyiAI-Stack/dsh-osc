# dsh-osc-pr-chat

[English](README.md) | 中文

功能：把消息发到 GitHub Pull Request 评论，或发到本地 bot session。

包名：`@ruyiAi/dsh-osc-pr-chat`

依赖：role, agents, agentRuntime, tools

依赖的config.yaml配置：无

### 可调用Tools

1. pr_chat_send_to_pr：以当前登录用户身份，向指定 PR 发表评论。

2. pr_chat_send_to_bot：向本地 bot session 发送消息，不访问 GitHub。

### 注册的 Web API：

无

### 维护的 Service 状态

无
