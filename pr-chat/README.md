# dsh-osc-pr-chat

[中文](README.zh.md) | English

Purpose: Send a message as a GitHub PR comment, or to a local bot session.

Package: `@ruyiAi/dsh-osc-pr-chat`

Dependencies: role, agents, agentRuntime, tools

config.yaml: none

### Tools

1. pr_chat_send_to_pr: Post a comment to a pull request as the logged-in user.

2. pr_chat_send_to_bot: Send a message to a local bot session without calling GitHub.
